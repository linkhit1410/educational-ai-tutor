# Week 4: Adaptive Behavior Evaluation

## Purpose

The purpose of this evaluation is to test whether the tutor can choose an appropriate level of support based on the student's intent and demonstrated effort.

A successful adaptive tutor should not give the same kind of response to every student. Instead, it should adjust its response based on what the student is trying to accomplish and how much effort the student has shown.

---

# Evaluation Criteria

For each sample interaction, I evaluate:

- Student intent
- Apparent effort level
- Recommended support level
- Whether the response protects academic integrity
- Whether the response promotes learning
- Possible improvements

---

# Sample Interaction 1: Concept Learning

## Student Question

What is polymorphism?

## Student Intent

Concept Learning

## Apparent Effort

Moderate Effort

The student is asking a direct concept question. They are not trying to get assignment code, but they also have not shown detailed reasoning yet.

## Recommended Support Level

Level 2: Conceptual Hint

## Appropriate Tutor Response

The tutor should explain polymorphism using retrieved CISC 230 materials and course terminology. The response should be clear, concise, and include a check-for-understanding question.

## Why This Promotes Learning

This helps the student build conceptual understanding without overwhelming them. A check-for-understanding question encourages the student to actively process the explanation.

## Possible Improvement

The tutor should avoid unsupported examples unless they appear in the retrieved course materials.

---

# Sample Interaction 2: Assignment Clarification

## Student Question

What does Homework 3 require?

## Student Intent

Assignment Clarification

## Apparent Effort

Moderate Effort

The student is asking about requirements, not directly asking for a solution.

## Recommended Support Level

Level 3: Strategic Guidance

## Appropriate Tutor Response

The tutor should clarify the assignment goals and relevant concepts only if safe assignment materials are available. It should avoid giving full code or completing the assignment.

## Why This Promotes Learning

This helps the student understand the task while preserving their responsibility to complete the work.

## Possible Improvement

The tutor needs access to professor-approved assignment descriptions. It should not retrieve solutions, answer keys, or previous student submissions.

---

# Sample Interaction 3: Debugging With Low Detail

## Student Question

Why am I getting a NullPointerException?

## Student Intent

Debugging Support

## Apparent Effort

Low to Moderate Effort

The student names an error but does not provide code, a line number, or what they tried.

## Recommended Support Level

Level 1 or Level 2

## Appropriate Tutor Response

The tutor should ask for the error message, line number, and relevant code. It can briefly explain that a `NullPointerException` usually happens when code tries to use an object reference that is currently `null`.

## Why This Promotes Learning

This teaches the student to investigate the error instead of only asking for a fix. It encourages a debugging process based on evidence.

## Possible Improvement

The tutor should avoid guessing the exact cause without seeing the code.

---

# Sample Interaction 4: Direct Solution Request

## Student Question

Can you write my Homework 3?

## Student Intent

Direct Solution Request

## Apparent Effort

Low Effort

The student is asking the tutor to complete graded work.

## Recommended Support Level

Level 1: Reflection Prompt and Refusal

## Appropriate Tutor Response

The tutor should refuse to write the homework. It should redirect the student toward learning support by offering to explain the relevant concept, help interpret the assignment, or guide a first step.

## Why This Promotes Learning

This protects academic integrity and prevents the tutor from replacing the student's learning process.

## Possible Improvement

The tutor should sound supportive rather than punitive. It should make clear that help is still available in a learning-focused way.

---

# Sample Interaction 5: Design Reflection

## Student Question

I think inheritance should be used here. Am I on the right track?

## Student Intent

Reflection or Design Reasoning

## Apparent Effort

Moderate Effort

The student has an idea but has not fully explained the design.

## Recommended Support Level

Level 1 or Level 3

## Appropriate Tutor Response

The tutor should ask the student to explain the relationship between the classes. It should guide them to check whether the relationship is an is-a relationship and what behavior belongs in the superclass.

## Why This Promotes Learning

This encourages the student to reason about object-oriented design instead of relying on the tutor to decide.

## Possible Improvement

The tutor should ask for the specific classes involved before giving detailed guidance.

---

# Sample Interaction 6: High-Effort Debugging

## Student Question

I created an abstract superclass and three subclasses. My overridden methods are not behaving correctly.

## Student Intent

High-Effort Technical Help

## Apparent Effort

High Effort

The student has already attempted a design and identified a specific problem area.

## Recommended Support Level

Level 4: Targeted Technical Hint

## Appropriate Tutor Response

The tutor can ask the student to compare method signatures, return types, parameter lists, and superclass/subclass relationships. It can give a targeted hint about overriding without rewriting the full solution.

## Why This Promotes Learning

The student has shown meaningful effort, so more specific guidance is appropriate. The tutor still preserves learning by asking the student to inspect and reason through the issue.

## Possible Improvement

If the student provides code, the tutor could give line-specific debugging guidance while still avoiding a full rewritten solution.

---

# Overall Findings

Adaptive behavior improves tutoring quality because it allows the tutor to respond differently to different learning situations.

Low-effort or direct-solution requests should receive less direct help and more redirection. Moderate-effort requests should receive conceptual hints or strategic guidance. High-effort requests can receive more targeted technical feedback.

This approach supports academic integrity while still helping students learn.

---

# Main Takeaway

The tutor should adapt based on both student intent and student effort.

This makes the system different from a general chatbot. A general chatbot may answer every question directly, but an educational tutor should choose the amount of help that best supports learning.
