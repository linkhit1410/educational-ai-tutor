# Setup Notes

For Week 1, I installed and tested Ollama to run a local language model on my computer.

## Installation Check

After installing Ollama and opening the Ollama app, I checked that the terminal command worked by running:

```bash
ollama --version
```

The terminal showed:

```text
ollama version is 0.30.11
```

## Running the Model

I started the local model by running:

```bash
ollama run llama3.2
```

This opened an interactive terminal chat where I could ask the model programming-related questions.
