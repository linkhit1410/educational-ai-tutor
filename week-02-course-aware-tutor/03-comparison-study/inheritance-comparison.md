# Comparison Study: Inheritance Question

## Student Question

What is inheritance?

## Version A: Tutor Without Retrieval

The tutor gave a generally correct explanation of inheritance. It explained that inheritance allows one class to inherit properties and behavior from another class. It used a family analogy and a Vehicle/Car example.

This response was educationally useful because it explained the concept clearly and asked a follow-up question. However, it was generic. It did not refer to CISC230 course materials, course vocabulary, or the specific way the course introduces inheritance.

## Version B: Tutor With Retrieval

Retrieved course context:

Source: oop_concepts.txt

Inheritance allows one class to reuse fields and methods from another class.
The superclass contains shared behavior, and the subclass can add or override behavior.

The tutor response was more aligned with the course materials. It used terms such as superclass, subclass, shared behavior, and override. These terms matched the retrieved course context.

## Difference

Retrieval improved course alignment. Both responses were correct, but the retrieval-supported response was more connected to the language and concepts in the course materials.

## Educational Reflection

This example shows that retrieval can help an AI tutor move from a general programming explanation to a course-aware explanation. The tutor still needs to guide learning rather than simply provide answers, but retrieval helps it stay closer to the course context.
